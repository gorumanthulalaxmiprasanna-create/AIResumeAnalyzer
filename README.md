# AI Resume Analyzer

A desktop application developed in Java that analyzes PDF resumes, extracts text, provides ATS-based suggestions, and stores resume details in a MySQL database.

---

## Features

✔ Upload PDF Resume

✔ Extract Resume Text using Apache PDFBox

✔ ATS Resume Analysis

✔ Suggest Resume Improvements

✔ Save Resume Analysis to MySQL Database

---

## Technologies Used

- Java
- Java Swing
- JDBC
- MySQL
- Apache PDFBox
- NetBeans IDE
